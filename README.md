# Frontend_Webpage

This project demonstrates a responsive webpage with a collapsible left menu, a fixed navbar, and a functional button that toggles between "Open" and "Close" text based on the state of the menu. The page is designed to be responsive and works across multiple screen sizes.

## Features

- Fixed Navbar at the top.
- Left Menu that can be collapsed and expanded.
- Main content area in the center.
- Right panel on the side.
- Footer at the bottom.
- Button text toggles between "Open" and "Close" based on the state of the left menu.
- Responsive design for different screen sizes.

## Technologies Used

- HTML
- CSS
- JavaScript

## Setup Instructions

### Prerequisites

To run this project, you need the following:
- A web browser (Chrome, Firefox, Edge, etc.)
- Text editor or IDE (e.g., VS Code)

### Steps to Run the Project Locally

1. **Clone the repository**:
   - Open your terminal/command prompt and run the following command to clone the project:
     ```bash
     git clone https://github.com/your-username/project-name.git
     ```

2. **Navigate to the project directory**:
   - Change into the project folder:
     ```bash
     cd project-name
     ```

3. **Open the project in your browser**:
   - You can simply open the `index.html` file in your browser. However, to run the project more dynamically and get live updates without refreshing the page, use **VS Code's Live Server** extension.

   **To use Live Server:**

   1. Open the project folder in **Visual Studio Code**.
   2. Install the **Live Server** extension from the VS Code extensions marketplace if you haven't already.
   3. Right-click on the `index.html` file and click **Open with Live Server**.
   
   Alternatively, you can also click the **Go Live** button at the bottom of VS Code (on the status bar) to launch the live server.

4. **Start interacting with the webpage**:
   - The left menu can be toggled using the button. When collapsed, the button text will show "Open", and when expanded, the button will show "Close".
   - Resize the browser to see the responsiveness of the layout.


### Files Explanation

- **index.html**: The main HTML file that contains the structure of the webpage.
- **style.css**: The CSS file that contains styles for the layout and design.
- **script.js**: The JavaScript file responsible for the button functionality and collapsing/expanding the left menu.
